# Disclosure Boundary

This repository is intentionally a sanitized case study.

It does not contain:

- customer, partner, or legacy-product source material;
- UI captures or configuration extracted from another product;
- private network addresses, credentials, remote-access scripts, or deployment packages;
- vendor binaries or libraries without reviewed redistribution rights;
- captured fiber images, site logs, calibration values, or process recipes;
- production algorithms or source code whose ownership and release status have not been cleared;
- high-voltage discharge, heating, or other hazardous process implementation details.

The architecture and validation material was rewritten at a generic engineering level to demonstrate experience without making the original private project reconstructable.
